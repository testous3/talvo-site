# talvo-site

Site public de l'application Talvo, hébergé via GitHub Pages.

- `index.html` — landing page
- `privacy.html` — politique de confidentialité (requise par l'App Store / Google Play)
- `terms.html` — conditions générales d'utilisation
- `config.json` — configuration de version consommée par l'app au lancement (min version, lien store) : en dessous de `minVersion`, l'app force la mise à jour
- `assets/` — icône, mascotte, screenshots, feuille de style partagée

## URLs (une fois GitHub Pages activé)

- Landing : `https://testous3.github.io/talvo-site/`
- Politique de confidentialité : `https://testous3.github.io/talvo-site/privacy.html`
- CGU : `https://testous3.github.io/talvo-site/terms.html`
- Config app : `https://testous3.github.io/talvo-site/config.json`
